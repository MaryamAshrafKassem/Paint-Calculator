# Paint-Calculator
Paint Mix Calculator is a hobby project that converts digital colors (HEX/RGB) into approximate Red–Yellow–Blue paint mixing ratios.

The goal is to help beginner artists bridge the gap between digital color selection and real-world paint mixing. While digital screens use RGB (additive color), traditional paint uses subtractive mixing — this tool provides a practical approximation for educational use.

Features (Planned / Current)

🎨 Color picker input (HEX/RGB)

📊 Estimated Red / Yellow / Blue mix percentages

🧠 Beginner-friendly mixing guidance

🌍 Fully browser-based (no backend required)

This project is open-source and built for learning, experimentation, and collaboration.
